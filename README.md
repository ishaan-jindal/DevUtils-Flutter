# DevUtils

A clean and lightweight developer utility toolbox built with Flutter.

DevUtils provides commonly used developer tools in a fast, modern, and offline-friendly app.

---

# Features

## Current Tools
- JSON Formatter & Validator
- Timestamp Converter
- JWT Decoder
- API Tester

## Planned
- Regex Tester
- Base64 Encoder/Decoder
- URL Encoder/Decoder
- Hash Generator
- Color Converter
- Diff Checker
- SQL Formatter
- Markdown Preview
- Snippet Vault
- Workspace System

# Getting Started

## Clone Repository

```bash
git clone https://github.com/ishaan-jindal/DevUtils-Flutter.git
```

## Install Dependencies

```bash
flutter pub get
```

## Run App

```bash
flutter run
```
